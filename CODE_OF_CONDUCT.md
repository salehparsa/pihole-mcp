# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers, assume good faith, and don't harass or discriminate. Harassment, personal attacks and publishing others' private information (including their network data) are not acceptable.

Maintainers may remove comments, commits and contributions that violate this code, and may temporarily or permanently ban contributors for behaviour they deem inappropriate. Report concerns privately to the maintainers via a GitHub Security Advisory or by contacting the repository owner through their GitHub profile; reports are handled confidentially.
